# Homebrew tap for Flashcat

[Flashcat](https://github.com/TomTomsen765/flashcat) is a local AI assistant for the macOS terminal.

```sh
brew install tomtomsen765/tap/flashcat
```

Update with `brew upgrade flashcat`. Flashcat needs LM Studio (https://lmstudio.ai/download) or Ollama;
the first start offers to download the default model.
